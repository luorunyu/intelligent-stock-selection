# 策略五：高位做空状态

该策略只使用前复权收盘价，为每只股票的每个交易日标记高位状态。状态引擎本身
不选择具体做空点；另附的状态回测报告按下述固定规则解释这些状态。

默认参数：

- 半年窗口：120个交易日；
- 最高点确认：从运行最高收盘价回落30%；
- 波峰开启：从当前波谷反弹10%；
- 波峰结束：收盘价回落到波峰开始价格；
- 最高点热度：当前收盘价相对前10个交易日均价的涨幅；
- 波峰热度：当前收盘价相对波谷日前5个交易日均价的涨幅。

## 状态流转

策略按以下顺序识别一个完整周期：

```text
NORMAL
  -> HIGH_CANDIDATE
  -> 后续从参考高点回落达到30%时：
       候选起点至参考高点回填为 HIGH_CONFIRMED
       参考高点后至确认日前回填为 HIGH_DRAWDOWN
       确认日进入 TROUGH_WAIT_REBOUND
  -> PEAK_1 -> PEAK_1_PULLBACK
  -> PEAK_2 -> PEAK_2_PULLBACK
  -> PEAK_3 -> PEAK_3_PULLBACK
  -> PEAK_N -> PEAK_N_PULLBACK -> ...
```

高点确认后，任何阶段如果收盘价严格高于原参考高点，当日改为
`INVALID_HIGH_NEW_HIGH`，原周期失效，并以该日新高开始下一个候选周期。

## 每个状态的定义

### 普通与初始高位

| 值 | 枚举 | 中文状态 | 精确定义 | 策略二分类 |
| ---: | --- | --- | --- | --- |
| `0` | `NORMAL` | 普通状态 | 尚未进入高位周期。常见于历史数据不足120个交易日，或收盘价未达到前120个交易日最高收盘价。 | 非做空范围 |
| `10` | `HIGH_CANDIDATE` | 最高点候选区域 | 当日收盘价大于或等于前120个交易日的最高收盘价时开始。候选期内若收盘价达到或超过当前参考高点，参考高点的日期和价格同步更新；只要从运行中的参考高点回落尚未达30%，仍保持此状态。它表示“可能是高位”，尚未被后续回落确认。 | 做空范围 |
| `20` | `HIGH_CONFIRMED` | 已确认最高点区域 | 当后续收盘价较参考高点回落至少30%时，程序将“候选起点到参考高点”的历史记录回填为此状态。因此它通常是事后确认的历史高位区间，不是确认日当天的实时状态。 | 做空范围 |
| `30` | `HIGH_DRAWDOWN` | 最高点后的确认前回落 | 只有在回落达到30%后才会回填：标记参考高点次日起、到首次达到30%回落的前一日为止的过渡区间。 | 非做空范围 |
| `40` | `TROUGH_WAIT_REBOUND` | 回落已达阈值，寻找波谷并等待反弹 | 首次达到30%回落的当日进入。之后持续用更低或相等的收盘价更新参考波谷，直到收盘价从当前波谷反弹至少10%。该状态只用于第一波反弹出现之前。 | 非做空范围 |

### 反弹波峰

收盘价从当前参考波谷反弹至少10%的当日，记为该波峰的开始日，
当日收盘价记为“波峰开始价”。波峰期内不要求股价每日上涨；只要后续收盘价仍严格
高于波峰开始价，就保持当前波峰状态。

| 值 | 枚举 | 中文状态 | 精确定义 | 策略二分类 |
| ---: | --- | --- | --- | --- |
| `51` | `PEAK_1` | 第一波峰区域 | 第一次从当前波谷反弹至少10%后的波峰阶段。 | 做空范围 |
| `52` | `PEAK_2` | 第二波峰区域 | 第一波峰结束并形成新波谷后，第二次从当前波谷反弹至少10%的波峰阶段。 | 做空范围 |
| `53` | `PEAK_3` | 第三波峰区域 | 第二波峰结束并形成新波谷后，第三次从当前波谷反弹至少10%的波峰阶段。 | 做空范围 |
| `59` | `PEAK_N` | 第N波峰区域 | 第4波及以后的波峰共用此枚举值。实际序号保存在 `peak_number`，中文描述会显示为“第4波峰区域”、“第5波峰区域”等。 | 做空范围 |

### 波峰结束后的回落

波峰开始日之后，收盘价首次小于或等于该波峰开始价时，当日进入对应的
回落状态，并从当日开始重新跟踪波谷。之后每出现更低或相等的收盘价，参考波谷就下移；
再次从当前波谷反弹至少10%时，进入下一波峰。

| 值 | 枚举 | 中文状态 | 精确定义 | 策略二分类 |
| ---: | --- | --- | --- | --- |
| `61` | `PEAK_1_PULLBACK` | 第一波峰结束后的回落 | 第一波峰结束后，正在寻找新波谷并等待第二波反弹。 | 非做空范围 |
| `62` | `PEAK_2_PULLBACK` | 第二波峰结束后的回落 | 第二波峰结束后，正在寻找新波谷并等待第三波反弹。 | 非做空范围 |
| `63` | `PEAK_3_PULLBACK` | 第三波峰结束后的回落 | 第三波峰结束后，正在寻找新波谷并等待第四波反弹。 | 非做空范围 |
| `69` | `PEAK_N_PULLBACK` | 第N波峰结束后的回落 | 第4波及以后的波峰回落共用此枚举值。实际序号由 `peak_number` 保存。 | 非做空范围 |

### 失效告警

| 值 | 枚举 | 中文状态 | 精确定义 | 分类 |
| ---: | --- | --- | --- | --- |
| `90` | `INVALID_HIGH_NEW_HIGH` | 最高点确认后再次创新高，原判断失效 | 进入回落或波峰阶段后，当日收盘价严格高于本周期参考高点。当日输出 `alert_code=CONFIRMED_HIGH_BROKEN`，原周期终止，该新高成为下一周期的候选起点和新参考高点。 | 异常告警，不归入做空范围 |

## 判断边界和字段

- 策略只使用前复权收盘价，不使用盘中高低价、成交量或行业信息。
- 120日新高触发使用 `>=`；30%回落确认和10%反弹开启都包含恰好等于阈值的情况。
- 波峰结束使用“收盘价 `<=` 波峰开始价”；旧高点失效则要求“收盘价 `>` 参考高点”。
- `cycle_id` 是高位周期编号；`peak_number` 是当前周期内的反弹波峰序号。
- `reference_high_*` 保存本周期参考高点；`reference_low_*` 保存当前参考波谷。
- `total_mv` 和 `circ_mv` 分别是对应交易日的总市值、流通市值，来自本地
  `daily_basic`。CSV/JSON 保留 Tushare 原始单位万元，报告和图表换算为亿元展示。
- 高位热度是当日收盘价相对前10个交易日均价的涨幅；波峰热度是当日收盘价相对“波谷日之前5个交易日均价”的涨幅。热度只是输出指标，不参与状态转换。
- `HIGH_CONFIRMED` 和 `HIGH_DRAWDOWN` 会在30%回落确认后回填历史，因此使用最终完整的 `states.csv` 做历史回测时，必须注意这两个状态包含后视确认，不能当成当日已知信号。

以上“做空范围”只是项目中筛选方案二对状态的程序分组，不代表具体交易点，也不构成投资建议。

## 状态做空回测报告

使用 `--write-report` 时，除原有的 `states.csv`、`report.json` 和 `report.md`
外，还会生成以下四类状态回测报告：

- `short_trade_backtest.md`：全部可识别交易；
- `short_trade_backtest_avg_mv_below_300yi.md`：持有期间平均总市值低于300亿元；
- `short_trade_backtest_avg_mv_at_least_300yi.md`：持有期间平均总市值大于等于300亿元。
- `short_trade_backtest_lendable_YYYYMMDD.md`：报告日融券状态正常且可用数量大于0的固定股票池；仅在找到同日期融券文件时生成。

每类回测报告都会同时生成 `.md` 和同名 `.html`。Markdown 版保留便于
查看源文本的表格；HTML 版取消中间窄版心，使用整个浏览器窗口展示完整的20列
逐笔交易明细。Markdown 报告顶部也提供对应宽屏 HTML 版的链接。

每笔交易的平均总市值，是从开仓日至平仓日、失效日或报告日之间，所有存在
`daily_basic.total_mv` 的交易日取算术平均。Tushare 的单位为万元，因此300亿元对应
`total_mv=3,000,000`。边界统一放入“大于等于300亿元”组；整个持有区间都没有市值
数据的交易不会强行归类，并会在分组报告开头显示排除数量。报告明细同时展示平均总市值
和实际参与平均值计算的交易日数量。

可融券股票池默认从
`data_cache/securities_lending/daily/YYYYMMDD.xls` 读取，也可通过
`--lending-file` 指定。该报告使用报告日的融券快照筛选整段历史交易，适合回答“当前可融券
股票组成的池子中，策略历史表现如何”，但不能证明历史信号发生时同样有券源。报告没有计入
历史可借数量变化、融券费率和强制归还风险。

这些报告使用以下交易规则：

- 空仓时首次进入 `HIGH_CANDIDATE`，按当日收盘价建立一笔候选高点做空交易；
- 首次进入某个 `PEAK_n`，按该波峰开始日收盘价建立一笔该波峰做空交易；
- `HIGH_CANDIDATE` 交易在首次进入 `TROUGH_WAIT_REBOUND` 时按收盘价结束；
- `PEAK_n` 交易在首次进入相同序号的 `PEAK_n_PULLBACK` 时按收盘价结束；
- 同一状态连续出现时不重复开仓，不同股票和不同周期不会交叉配对；
- 出现 `INVALID_HIGH_NEW_HIGH`，或周期已经切换但没有出现对应结束状态时，
  该交易标记为“已失效”；报告日仍未出现结束状态则标记为“持仓中”；
- 已失效和持仓中的交易不计入已完成交易的胜率、平均收益和复利统计，
  但逐笔明细保留截至失效日或报告日的浮动收益、MFE、MAE 和最大回撤。

状态算法在跌幅达到30%后会把原 `HIGH_CANDIDATE` 历史行回填为
`HIGH_CONFIRMED`。回测会通过同周期最早的候选记录及其
`state_start_date/state_start_close` 还原当时实际可观察的候选起点，
不会把事后出现的 `HIGH_CONFIRMED` 当成开仓信号。若新周期从上一周期的
`INVALID_HIGH_NEW_HIGH` 当日内部启动，则等到下一条实际输出的
`HIGH_CANDIDATE` 才开仓。

报告中的主要指标定义如下：

| 指标 | 定义 |
| --- | --- |
| 做空收益率 | `开仓价 / 平仓价 - 1`；大于0为盈利，小于0为亏损。 |
| 胜率 | 已完成交易中，做空收益率严格大于0的交易数 / 已完成交易数；收益为0单列为“平”。 |
| 持有交易日 | 从开仓到结束所跨越的该股票交易日数量，不包含开仓日。 |
| MFE | 持仓期间最低收盘价对应的最大有利收益，即 `开仓价 / 最低收盘价 - 1`。 |
| MAE | 持仓期间最高收盘价相对开仓价的最大不利涨幅，即 `最高收盘价 / 开仓价 - 1`。 |
| 单笔最大回撤 | 以 `开仓价 / 每日收盘价` 构造单笔做空权益曲线，计算从历史峰值到后续低点的最大跌幅。 |
| 逐笔复利收益 | 按平仓日顺序连接所有已完成交易的收益；仅用于信号比较。 |
| 逐笔复利最大回撤 | 上述逐笔复利曲线的最大回撤。 |

由于不同股票的交易可能重叠，逐笔复利指标没有考虑资金占用、仓位分配或组合并发，
不等于可直接执行的组合净值。所有统计均未计手续费、滑点、融券成本、涨跌停限制和
实际可融券约束。

还要特别注意：`PEAK_n_PULLBACK` 的状态定义就是收盘价回到或跌破波峰开始价，
所以能够正常到达结束状态的波峰交易，按上述收益公式天然不会出现负收益。报告会把
尚未结束和提前失效的信号单列，但它们不进入已完成交易胜率。因此波峰胜率接近100%
主要反映状态结束条件，不能脱离持仓中数量、失效数量、持有时间和持仓内回撤单独解读。

直接运行：

```powershell
python scripts/screen_stock_short_high_state.py --date 20260930
```

保存完整逐日状态 CSV、JSON 摘要、状态 Markdown 和状态做空回测 Markdown：

```powershell
python scripts/screen_stock_short_high_state.py `
  --date 20260930 `
  --write-report
```

明确指定可融券文件：

```powershell
python scripts/screen_stock_short_high_state.py `
  --date 20261009 `
  --lending-file data_cache/securities_lending/daily/20261009.xls `
  --write-report
```

只处理指定股票：

```powershell
python scripts/screen_stock_short_high_state.py `
  --date 20260930 `
  --stock-code 000001.SZ
```

## 状态画图

在项目根目录运行：

```bash
.venv/bin/python -m stock_selection.strategies.stock_short_high_state.plot_stock_short_high_states
```

默认读取最新输出目录中的 `states.csv`。在 `strategy_five_chart_codes.txt` 中每行填写一个
股票代码，只画清单中的股票；清单为空、只有空行或只有 `#` 注释时，绘制该 CSV 中的全部股票。
如果清单填写了内容但全部代码格式无效，仍会报错。股票范围和日期范围以 CSV 为准，
需要扩大范围时先运行策略 CLI 重新生成状态文件。

图表保存在状态文件同目录的 `charts/` 中，打开 `charts/index.html` 查看。
按回测汇总收益分入 `positive/`（正收益）和 `negative/`（非正收益）；没有回测交易或
没有可用回测收益的股票也生成图表，放入 `unclassified/`。缺少行情或行情与状态价格
不一致的股票会列在入口页的“未生成项目”中。
