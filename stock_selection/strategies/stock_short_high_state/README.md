# 策略五：高位做空状态
主要针对场景，是那种有大涨的情况，有大涨才会有大跌，不针对那种涨幅波动不大的情况，这种属于波峰波谷那种场景

该策略使用收盘价，为每只股票的每个交易日标记高位状态及开仓信号；另保存开盘价、最高价供画图核对。
回测结合成交量参考价和持仓限制统一决定实际开平仓，报告和图表复用同一份交易记录。

默认参数：

- 半年窗口：120个交易日；
- 高点候选条件：当日收盘价达到或超过前120个个股交易日最高收盘价（不含当日，包含等于）；
- 候选回调：当日收盘价从本轮运行最高收盘价回落至少10%，包含等于；
- 做空开仓范围：每次新进入候选回落 `HIGH_CANDIDATE_PULLBACK` 的信号，空仓时才开仓；同一行情周期可多次交易，所有波峰均只识别状态，不新开仓；
- 最高点确认：从运行最高收盘价回落20%；
- 波谷确认：低点后至少观察4个有效个股交易日、不创新低，最近4天至少3天收盘价高于前一天；平盘不算上涨，不满足则保持候选并滚动观察；
- 波峰开启：收盘价严格高于已确认波谷区域上沿，且相对下沿反弹至少10%；
- 波峰结束：收盘价回到波谷区域；跌破区域下沿则重新寻找波谷；
- 平仓参考放量：连续三天成交量严格递增，且第三天至少为第一天的3倍；取最后一组第三天收盘价；
- 正常平仓：仅在波谷实际确认当天，即 `observed_state=45` 且 `trade_date == trough_confirm_date`，按当天收盘价平仓；本周期第一波峰出现前还要求参考价绝对偏离不超过30%，出现后取消价格过滤；
- 独立盈利平仓：当前做空浮盈严格大于5%，且开仓后连续3个有效交易日收盘价高于前一天，按首次同时满足条件当天的收盘价平仓，不要求波谷状态或放量参考价；
- 持仓限制：每只股票同时只持有一笔，持仓期间和平仓当日的新开仓信号跳过，不补开；
- 最高点热度：当前收盘价相对前10个交易日均价的涨幅；
- 波谷和波峰热度：当前收盘价相对波谷区域下沿的涨幅。

当前默认回调阈值来自 `screen.py` 的 `DEFAULT_CANDIDATE_PULLBACK_PCT = 0.10`，
可通过 `--candidate-pullback-pct` 覆盖；高点确认阈值来自 `DEFAULT_CONFIRM_DRAWDOWN_PCT = 0.20`，
可通过 `--confirm-drawdown-pct` 覆盖。下文按当前默认值举例，实际运行以传入参数为准。

## 状态流转

策略按以下顺序识别一个完整周期：

```text
NORMAL
  -> 收盘价达到或超过前120个交易日最高收盘价：HIGH_CANDIDATE (10)
  -> 从运行最高收盘价回落至少10%：HIGH_CANDIDATE_PULLBACK (15)
       回升到10%回落阈值以内则回到10；之后再次达到阈值时产生新的开仓信号
  -> 回落达到20%：
       只将参考最高收盘价当天回标 HIGH_CONFIRMED (20)
       当天进入 TROUGH_CANDIDATE (41)
  -> 低点后至少4个交易日不创新低，最近4天至少3天收盘上涨：TROUGH_REGION (45)
       候选低点至确认日的记录回填为 TROUGH_REGION
  -> 突破区域上沿，且从下沿反弹至少10%：PEAK_1 (51)
  -> 回到波谷区域：TROUGH_REGION (45)
  -> 再次满足波峰开启条件：PEAK_2 (52) -> ...

波谷区域或波峰阶段跌破区域下沿：
  -> TROUGH_CANDIDATE (41) -> 重新确认 TROUGH_REGION (45)
```

高点确认后，任何阶段如果收盘价严格高于原参考高点，当日改为
`INVALID_HIGH_NEW_HIGH`，原周期失效。该日收盘价达到或超过前120个交易日最高收盘价时，
在内部启动下一个候选周期；否则回到普通阶段，等待后续日期满足该条件。
候选期内创新高只更新参考高点，不触发失效。若同价高点出现多次，参考高点取最后一次。
若首次达到候选回调阈值当天也从高点回落达到20%，当日实际状态输出41，但独立的
`entry_signal=15` 保留，回测仍能在当日收盘开仓，最早下一交易日平仓。

## 每个状态的定义

### 普通与初始高位

| 值 | 枚举 | 中文状态 | 精确定义 | 当前回测用途 |
| ---: | --- | --- | --- | --- |
| `0` | `NORMAL` | 普通状态 | 尚未进入高位周期。历史不足120个交易日，或当日收盘价低于前120个交易日最高收盘价时，继续保持普通状态。 | 不开仓 |
| `10` | `HIGH_CANDIDATE` | 最高点候选区域 | 当日收盘价大于或等于前120个交易日最高收盘价时启动，不附加涨幅条件。候选期内达到或超过参考高点会更新高点日期和价格；当日回落幅度不足10%时输出10。 | 不开仓 |
| `15` | `HIGH_CANDIDATE_PULLBACK` | 最高点候选回调区域 | 候选阶段，当日收盘价相对本轮运行最高收盘价回落至少10%、尚未达到20%高点确认阈值时输出15；回升到10%回落阈值以内则回到10。 | 每次新进入回调区间时保存独立开仓信号，空仓时按当日收盘价开仓；同周期可多次触发 |
| `20` | `HIGH_CONFIRMED` | 已确认最高点 | 后续收盘价较参考高点回落至少20%时，只把参考最高收盘价当天回标为20，其余候选和候选回调历史行保留。这个高点标记是事后确认的，实际确认日输出41。若高点行原为90，则保留90。 | 不作为开仓点 |

例如前120个交易日最高收盘价为10元，今天收盘10元或10.01元均满足候选启动条件，
9.99元不满足。窗口不含今天，按个股行情记录计数，停牌日不计入；历史不足完整窗口时不启动。
可通过 `--lookback-days` 调整窗口，默认120。

状态值15是枚举编号，回调比例由 `--candidate-pullback-pct` 决定，当前默认10%。
最高点确认按相对运行最高收盘价回落20%判断，例如高点100元、跌至80元进入41。

### 候选回调与实际开仓

- 计算 `drawdown = 1 - 当日收盘价 / 本轮运行最高收盘价`，达到 `candidate_pullback_pct` 即为候选回调；当前默认至少10%，包含等于，不要求K线颜色或连续下跌天数。
- 例如本轮最高收盘价100元，首次收盘到90元时触发；91元尚未触发。若之后运行最高收盘价更新为110元，则阈值价变为99元。
- 候选阶段每日重新判断：回落不足阈值输出10，达到阈值输出15；达到20%确认阈值当天转为41，但独立开仓信号仍保留。
- 每次从回调阈值以内重新达到阈值，保存当日独立 `entry_signal=15`，信号类型为 `CANDIDATE_DRAWDOWN_THRESHOLD`；连续处于回调区间不逐日重复发信号。候选期内先回升到阈值以内即可重新准备下一次信号，不必创新高。
- 每只股票同时只持有一笔；持仓期间或平仓当日的新开仓信号跳过，不延后补开。平仓后可接受同一行情周期内后续新的回调信号，按当日收盘价做空；旧信号不重放，不会因为空仓就自动对连续回调重复开仓。
- `peak_entry_states=frozenset()`，所有 `PEAK_n` 都不开仓。第一波峰实际出现仍会取消本周期波谷正常平仓的参考价过滤。

例如候选高点100元，收盘价依次为95、90、88、93、89元：90元当天发出一次回调信号；
88元仍在回调区间，不再发信号；93元回到阈值以内，89元再次进入回调区间时发出新信号。
如果第一笔尚未平仓，89元的新信号跳过；如果之前已经平仓且不是同日平仓，则可按89元新开仓。

`cycle_id` 记录行情状态周期，开平仓不会改变它；是否可开仓只检查实际持仓和当天的新信号，
不再用“本周期开过仓”阻止后续交易。报告、采样收益和图表共用这套持仓规则。

### 波谷候选与确认

| 值 | 枚举 | 中文状态 | 精确定义 | 当前回测用途 |
| ---: | --- | --- | --- | --- |
| `41` | `TROUGH_CANDIDATE` | 波谷候选区域 | 初次从高点回落达到20%，或已确认波谷/波峰阶段跌破当前波谷区域下沿时进入。低点后至少观察4个有效交易日、不创新低，且最近4天至少3天收盘高于前一天才确认；否则保持候选并滚动观察，更低收盘价更新低点、重新计时。 | 不触发波谷正常平仓；独立盈利平仓、止损和失效强平仍可触发 |
| `45` | `TROUGH_REGION` | 已确认波谷区域 | 满足不创新低和上涨天数条件后，将候选低点日至实际确认日的历史行回填为45。区域下沿为低点收盘价，上沿为低点至确认日的最高收盘价；确认可能晚于第5天。之后尚未突破波峰开启条件、也未跌破下沿时继续输出45。波峰回到区域内也输出45。 | 仅实际确认日触发波谷正常平仓：`observed_state=45` 且当天等于 `trough_confirm_date`，仍受参考价过滤；不按回填低点日提前平仓 |

例如收盘价70、71、72、71、73，期间没有低于70元，后4天有3天收盘上涨，第5天确认区域 `[70, 73]`，
这5天回填为45，实际可知的确认时间记录在 `trough_confirm_date`。
若期间出现69元，则以69元当天重新开始计数；相等的低点不会重置计数。
新增 `observed_state/observed_state_name` 保留当日实际状态：上述前4天仍为41，第5天为45。
波谷正常平仓使用实际状态和确认日期；符合参考价条件时，第5天按73元收盘价平仓，
不会按第1天的70元低点价格平仓。
若收盘价是70、75、74、73、72，后4天虽都高于70，但只有1天上涨，因此不确认。
第五天不满足时保留候选低点，继续检查最近4天；例如后续为73、74、75，则第8天确认。
平盘不算上涨，相等低点不重置低点日期。确认日未通过参考价过滤时，等待后续新的波谷确认日或其他平仓条件。

### 反弹波峰

已有确认波谷区域后，收盘价同时满足“严格高于区域上沿”和“相对下沿反弹至少10%”，
才开启下一波峰；当日记录为波峰开始日和开始价。波峰不要求每日上涨，
后续价格保持在区域上沿以上时继续输出相同波峰状态。
回到区域内转为45，跌破下沿转为41；下一次满足开启条件时波峰序号加1。

| 值 | 枚举 | 中文状态 | 精确定义 | 当前回测用途 |
| ---: | --- | --- | --- | --- |
| `51` | `PEAK_1` | 第一波峰区域 | 本周期第1次满足波峰开启条件。 | 不开仓；首次实际出现后取消本周期波谷正常平仓的参考价过滤 |
| `52` | `PEAK_2` | 第二波峰区域 | 第1波结束后，本周期第2次满足波峰开启条件；可沿用原波谷区域，不要求形成新低点。 | 仅识别状态，不新开仓 |
| `53` | `PEAK_3` | 第三波峰区域 | 第2波结束后，本周期第3次满足波峰开启条件。 | 仅识别状态，不新开仓 |
| `59` | `PEAK_N` | 第N波峰区域 | 第4波及以后共用此枚举值，实际序号由 `peak_number` 保存，中文描述显示具体序号。 | 仅识别状态，不新开仓 |

### 失效告警

| 值 | 枚举 | 中文状态 | 精确定义 | 当前回测用途 |
| ---: | --- | --- | --- | --- |
| `90` | `INVALID_HIGH_NEW_HIGH` | 最高点确认后再次创新高，原判断失效 | 进入回落或波峰阶段后，当日收盘价严格高于本周期参考高点。当日输出 `alert_code=CONFIRMED_HIGH_BROKEN`，原周期终止；当日收盘价达到或超过前120个交易日最高收盘价时内部启动新候选周期，否则等待后续满足条件的日期。 | 持仓按当天收盘价强制平仓，计入已完成收益和胜率；图上显示异常叉号和平仓三角 |

## 判断边界和字段

- 高点、候选回调和波谷使用收盘价；波谷正常平仓另外使用成交量识别行情价格起点，不使用行业信息。
- 120日新高触发使用 `>=`；当前默认10%候选回调、20%高点确认和10%反弹阈值均包含等于，代码使用 `1e-12` 容差处理浮点边界。
- 初始周期与失效后重启周期使用同一候选条件：收盘价达到或超过前120个交易日最高收盘价，不附加涨幅门槛。前10日均价只用于计算 `heat`，不参与候选启动。
- 波峰开启还要求严格高于波谷区域上沿；回到或跌破上沿结束波峰，跌破下沿重新找波谷。旧高点失效要求收盘价严格高于参考高点。
- 波谷确认天数按个股数据中的交易日计数，包含候选低点当天；默认最早第5天，最近4天至少3天收盘上涨，不满足就继续滚动观察。
- `cycle_id` 是高位周期编号；`peak_number` 是当前周期内的反弹波峰序号。
- `reference_high_*` 保存本周期参考高点；`reference_low_*` 保存当前参考波谷。
- `vol` 保存每日成交量；缺失时保留空值，状态仍正常计算，但缺量的三天组合不能作为放量参考。
- 开盘价、最高价和成交量均为0的无成交占位记录（如停牌日）在行情标准化时过滤，不输出当日状态，也不计入120日窗口、波谷确认、连续收盘上涨或放量三日等个股交易日计数；恢复成交后接着上一个有效交易日计算。
- `open/high` 保存画图所需行情；过滤上述占位记录后，其他缺失或无效行情仍明确报错，不使用收盘价补造K线。
- `entry_signal` 为当日独立事件：0表示无信号、15表示候选回落、51/52/53/59表示对应波峰；不是每日重复的持仓信号。当前回测只接受15开仓，全部波峰事件保留用于观察，不计入实际开仓或持仓冲突跳过数。`entry_signal_type` 保存信号类型，`entry_pattern_start_date` 保存触发时参考高点的日期，`entry_reference_high_close` 保存判定用高点收盘价。
- `candidate_pullback_pct` 保存本次候选回调阈值，当前默认0.10；`trough_confirm_days`、`trough_min_up_days` 和 `trough_up_days` 保存波谷确认窗口、最低上涨天数和当前观察窗口内实际上涨天数。
- `lookback_days` 保存本次状态计算的窗口，画图回测沿用 CSV 中的值，默认120，不会丢失自定义窗口。
- `state/state_name` 是含事后回填的历史标签；`observed_state/observed_state_name` 是当日实际状态，回填时不覆盖，正常平仓只使用后者。
- `trough_zone_low/high` 保存确认波谷区域的上下沿；`trough_confirm_date` 保存实际确认日。
- `state_start_date/close` 是状态引擎阶段的起点，不一定是回测开仓点；回测使用独立 `entry_signal` 所在当天的日期和收盘价。
- `total_mv` 和 `circ_mv` 分别是对应交易日的总市值、流通市值，来自本地
  `daily_basic`。CSV/JSON 保留 Tushare 原始单位万元，报告和图表换算为亿元展示。
- 高位热度是当日收盘价相对前10个交易日均价的涨幅；已确认波谷和波峰热度是相对波谷区域下沿的涨幅。波谷尚未确认时热度为空。热度只是输出指标，不参与状态转换。
- `HIGH_CONFIRMED` 回标参考高点当天，`TROUGH_REGION` 回填低点至确认日；这些历史标记包含后视确认，不能把回填日期当成当天已知的确认日期。候选阶段的15不会因高点确认被整段覆盖。

状态定义以 `screen.py` 为准，实际开平仓以 `backtest.py` 为准，图表复用回测交易。
项目中筛选方案二的“做空范围”是另一套分类，不决定策略五的开仓点或黄框。

## 状态做空回测报告

使用 `--write-report` 时，每次运行都会新建一个带时间戳的批次目录，保存本次
`states.csv` 和以下四类状态回测报告：

- `short_trade_backtest.md`：全部可识别交易；
- `short_trade_backtest_avg_mv_below_300yi.md`：持有期间平均总市值低于300亿元；
- `short_trade_backtest_avg_mv_at_least_300yi.md`：持有期间平均总市值大于等于300亿元。
- `short_trade_backtest_lendable_YYYYMMDD.md`：报告日融券状态正常且可用数量大于0的固定股票池；仅在找到同日期融券文件时生成。

每类回测报告都会同时生成 `.md` 和同名 `.html`。Markdown 版保留便于
查看源文本的表格；HTML 版取消中间窄版心，使用整个浏览器窗口展示完整的20列
逐笔交易明细。Markdown 报告顶部也提供对应宽屏 HTML 版的链接。

目录格式为 `output/报告日期/charts_YYYYMMDD_HHMMSS_ffffff/`，例如：

```text
output/2026-10-20/charts_20261020_210000_123456/
    states.csv
    short_trade_backtest.md
    short_trade_backtest.html
    short_trade_backtest_avg_mv_below_300yi.md
    short_trade_backtest_avg_mv_below_300yi.html
    short_trade_backtest_avg_mv_at_least_300yi.md
    short_trade_backtest_avg_mv_at_least_300yi.html
    short_trade_backtest_lendable_20261020.md    # 找到同日期融券文件时生成
    short_trade_backtest_lendable_20261020.html
```

CLI 结束时会打印本次目录。重复运行 CLI 会创建新目录，同一报告日的历史报告和
状态文件均保留。随后运行画图命令，会将 `index.html` 及 `positive/`、`negative/`、
`unclassified/` 加到本批次目录；入口页提供本次回测 HTML 报告链接。
报告使用完整股票范围，不受画图清单限制。

每笔交易的平均总市值，是从开仓日至平仓日、失效日或报告日之间，所有存在
`daily_basic.total_mv` 的交易日取算术平均。Tushare 的单位为万元，因此300亿元对应
`total_mv=3,000,000`。边界统一放入“大于等于300亿元”组；整个持有区间都没有市值
数据的交易不会强行归类，并会在分组报告开头显示排除数量。报告明细同时展示平均总市值
和实际参与平均值计算的交易日数量。

可融券股票池默认从
`data_cache/securities_lending/daily/YYYYMMDD.xls` 读取，也可通过
`--lending-file` 指定。该报告使用报告日的融券快照筛选整段历史交易，适合回答“当前可融券
股票组成的池子中，策略历史表现如何”，但不能证明历史信号发生时同样有券源。报告没有计入
历史可借数量变化、融券费率和强制归还风险。

这些报告使用以下交易规则：

- 每次新进入10%回调区间时生成 `HIGH_CANDIDATE_PULLBACK` 独立信号，空仓时按当日收盘价做空开仓；同一行情周期可多次交易，所有波峰均不新开仓；
- 每只股票同时只允许一笔交易；持仓期间和平仓当天的新信号跳过，不延迟补开，平仓后等待下一次新信号；
- 波谷正常平仓：开仓日之后，`observed_state=TROUGH_REGION` 且 `trade_date == trough_confirm_date`，按实际确认当天收盘价平仓；默认最早第5天、最近4天至少3天收盘上涨，第一波峰实际出现前还要求参考价绝对偏离不超过30%；`TROUGH_CANDIDATE` 不触发这条平仓条件；
- 实际出现 `PEAK_1` 后本周期永久取消参考价限制，此后新的波谷确认日可直接平仓，即使没有参考价。波峰当天不因此直接平仓，也不会在已有持仓上叠加一笔；新周期重新启用过滤；
- 独立盈利平仓：当日做空浮盈严格大于5%，且开仓后连续至少3天收盘上涨，按当日收盘价平仓，结束原因记为 `PROFIT_REBOUND_EXIT`；不受波谷状态或参考价限制；
- 所有交易默认增加50%单笔回撤止损：做空权益为 `2 - 当日价格 / 开仓价`，
  相对持仓以来最高权益回撤达到50%时立即平仓，包含恰好50%；同日优先于状态退出或失效；
- 日线收盘价首次达到止损条件时，以对应的阈值价模拟成交，结束状态和原因为
  `MAX_DRAWDOWN_STOP`，计入已完成交易、收益和胜率；
- 持有天数、MFE、MAE、最大回撤及平均市值均截断到实际结束日；候选交易平仓后可接受同周期后续新的回调信号，无需等待新周期；
- 同一状态连续出现时不重复开仓，不同股票和不同周期不会交叉配对；
- 出现 `INVALID_HIGH_NEW_HIGH` 时按当天收盘价强制平仓，原因为 `HIGH_INVALIDATION_EXIT`；周期异常切换时按首次发现切换当天收盘价平仓，原因为 `CYCLE_CHANGE_EXIT`，不使用未来信息回填到前一天；
- 新高失效和周期切换平仓均计入已完成交易的胜率、平均收益和复利；同日回撤止损优先。报告日仍未平仓的交易记为持仓中，只保留浮动收益和持仓路径指标。

候选回测使用独立 `entry_signal=15` 记录开仓，同日转入41仍保留该信号，
不会把事后出现的 `HIGH_CONFIRMED` 当成开仓信号。

### 盈利后连续上涨平仓

`PROFIT_REBOUND_EXIT` 是独立的回测平仓原因，不新增状态。首次同时满足以下两项就按当天收盘价平仓：

1. 当日做空浮盈 `1 - 当日收盘价 / 开仓价 > 0.05`；恰好5%不触发，只要求触发当天收益达标。
2. 开仓后连续至少3个有效个股交易日 `close > 前一天 close`；从开仓后第一天与开仓日比较开始计数，开仓前的上涨不计入，下跌或平盘清零。

例如 `100（开仓）→88→89→90→91`，89、90、91连续三天收盘上涨，91当天做空浮盈为9%，
按91平仓；不等待波谷确认，也不检查放量参考价。连续三天指收盘价逐日上涨，不是K线收红。
同日平仓原因优先级为：回撤止损、周期切换/新高失效强平、独立盈利平仓、波谷确认平仓。
报告单列这类平仓笔数，图表的黄框在此日结束、蓝色正三角标记实际平仓，悬停显示原因和连续上涨天数。

### 行情价格起点与平仓过滤

1. 对每个交易日，使用该日已知的运行候选高点；候选期创新高时更新，高点确认后本周期固定，不使用未来才出现的最终高点。
2. 从该高点向前取 `lookback_days` 个个股交易日，不含高点当天；默认120天。找到最低收盘价，若最低价重复，取最后一次。历史不足整个窗口时不生成参考。
3. 在这个最低点至候选高点之间（两端包含），寻找连续三个个股交易日满足 `0 < V1 < V2 < V3` 且 `V3 / V1 >= 3` 的组合。三天都必须落在区间内；停牌日不计入。
4. 多组符合时取最后一组，即最靠近高点的一组，以第三天收盘价作为本轮行情价格起点，也是后续平仓参考价。缺量或找不到合格组合时不生成参考，不用其他价格代替。
5. 本周期实际出现第一波峰之前，仅在波谷实际确认日（`observed_state=45` 且当天等于 `trough_confirm_date`）计算 `abs(当日收盘价 / 参考价 - 1)`；不超过30%才允许波谷正常平仓，恰好30%包含在内。参考价用于过滤，实际按确认日收盘价计算收益；当天未通过则等待后续新的确认日或其他平仓条件。
6. 第一次实际出现 `PEAK_1` 后，本周期永久取消价格过滤，后续新的波谷确认日按收盘平仓；状态回填不会提前取消过滤。新周期重新启用限制，延续旧波谷区域不会产生新的确认日。

例如参考价10元：收盘14元偏离40%，视为暂时波谷，继续持仓；12元偏离20%，
满足平仓价格条件；13元偏离30%也满足。6元同样偏离40%，不满足。
以上价格过滤只用于第一波峰出现前的波谷正常平仓；其后即使没有合格参考价，也允许在新的波谷实际确认日平仓。
独立盈利平仓、50%回撤止损和新高失效强平全程生效，不受此过滤限制。

统一配置位于 `backtest.py` 的 `ShortTradeBacktestConfig`：
`peak_entry_states=frozenset()` 表示全部波峰均不开仓；其他配置包括
`trough_exit_states={TROUGH_REGION}`、`volume_expansion_multiple=3.0`、`max_price_origin_gap_pct=0.30`、
`profit_rebound_min_return_pct=0.05`、`profit_rebound_up_days=3`。
报告与画图共用该配置和回测结果，不需要分别修改。
同一只股票的交易不重叠；不同股票仍可并行持仓。

报告新增“平仓参考核对”表，逐笔显示结束/估值日实际状态、结束原因、参考高点及回看窗口、
窗口最低点、三天放量日期及成交量、量比、价格起点和绝对偏离，另显示开仓信号、参考价过滤取消日、跳过信号数、波谷观察上涨天数及开仓后连续上涨天数。没有参考时说明原因；
止损日的偏离按实际收盘价计算，不按模拟止损成交价计算。

例如100元开空、未出现浮盈时，止损价格为150元，收益为-50%。若先跌到80元，
做空权益峰值为1.2，之后涨到140元时权益降至0.6，已经从峰值回撤50%，
此时平仓收益为-40%。因此回撤止损和“从开仓价亏损50%”不是同一个阈值。

当前按阈值成交属于回测假设：止损日的平仓价可能不同于当日收盘价，未模拟跳空、
涨停无法买券还券等导致的超额亏损。配置位于 `backtest.py` 的
`ShortTradeBacktestConfig.max_drawdown_pct`，默认 `0.50`；报告和画图收益分类共用该配置。
该限制针对单笔交易，多笔亏损累计的逐笔复利最大回撤仍可能超过50%。
修改规则后需重新运行 CLI 生成报告，原有报告不会自动更新；图表分类也需重新运行画图。

报告中的主要指标定义如下：

| 指标 | 定义 |
| --- | --- |
| 做空收益率 | `1 - 平仓价 / 开仓价`；大于0为盈利，小于0为亏损。 |
| 胜率 | 已完成交易中，做空收益率严格大于0的交易数 / 已完成交易数；收益为0单列为“平”。 |
| 平均 / 中位收益 | 本报告全部已完成交易的均值 / 中位数；正收益、负收益的均值 / 中位数分别仅统计对应交易，无交易时显示“-”。胜负平按绝对收益不超过 `1e-12` 视为持平。 |
| 持有交易日 | 从开仓到结束所跨越的该股票交易日数量，不包含开仓日。 |
| MFE | 持仓价格路径对应的最大有利收益，即 `1 - 最低价 / 开仓价`；止损日使用模拟成交价结束路径。 |
| MAE | 持仓价格路径相对开仓价的最大不利涨幅，即 `最高价 / 开仓价 - 1`；止损日使用模拟成交价结束路径。 |
| 单笔最大回撤 | 以 `2 - 每日价格 / 开仓价` 构造单笔做空权益曲线，计算从历史峰值到后续低点的最大跌幅；默认达到50%即止损。 |
| 逐笔复利收益 | 按平仓日顺序连接所有已完成交易的收益；仅用于信号比较。 |
| 逐笔复利最大回撤 | 上述逐笔复利曲线的最大回撤。 |

由于不同股票的交易可能重叠，逐笔复利指标没有考虑资金占用、仓位分配或组合并发，
不等于可直接执行的组合净值。所有统计均未计手续费、滑点、融券成本、涨跌停限制和
实际可融券约束。

所有交易受50%回撤止损约束，已完成交易中包含独立盈利平仓、止损和新高失效平仓。报告把尚未结束的
交易单列，不进入已完成交易胜率；另外统计持仓期间和平仓当天跳过的信号数量。
市值分组报告的跳过信号数沿用阻止该信号开仓的持仓归组。不能脱离持仓中数量、
持有时间和持仓内回撤单独解读胜率。

新版状态文件位于 `charts_YYYYMMDD_HHMMSS_ffffff/` 批次目录，画图默认直接写入该目录，

带时间戳的图表目录。显式传入 `--output` 时使用指定图表目录。

都使用同一份结果。开平仓状态及止损参数统一在 `backtest.py` 的

- 黄框：每笔实际交易从开仓日至平仓日的区间，包含独立盈利平仓、50%回撤止损和失效强平；持仓中延伸至最后数据日，同一股票的黄框不重叠。

  收益、回撤、开仓信号、当日实际状态、放量参考、过滤取消日、连续上涨天数及跳过信号数。止损时同时说明模拟平仓价和触发日实际收盘价。跳过的开仓信号只在悬停/报告中展示，不画成实际开仓三角。
