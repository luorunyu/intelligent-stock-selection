# 策略五：高位做空状态

该策略只使用前复权收盘价，为每只股票的每个交易日标记高位状态。状态引擎本身
不选择具体做空点；另附的状态回测报告按下述固定规则解释这些状态。

默认参数：

- 半年窗口：120个交易日；
- 候选回调：从运行最高收盘价回落15%；
- 最高点确认：从运行最高收盘价回落30%；
- 本轮行情结束：从本轮参考最高收盘价回落35%，包含恰好35%；
- 反弹波谷确认：含候选低点当天共5个交易日，没有更低收盘价；
- 波峰开启：收盘价严格高于波谷区域上沿，且相对下沿反弹至少10%；
- 波峰结束：收盘价回到波谷区域；跌破区域下沿则重新寻找反弹波谷；
- 反转点确认：本轮结束后，含候选低点当天共10个交易日，没有更低收盘价；
- 最高点热度：当前收盘价相对前10个交易日均价的涨幅；
- 波谷和波峰热度：当前收盘价相对当前波谷区域下沿的涨幅。

当前代码保留了调试过滤：只分析 `trade_date > 20251015` 的数据，并在过滤后的
数据上重新计算120日窗口。更早的行情不会参与状态计算。

## 状态流转

策略按以下顺序识别一个完整周期：

```text
NORMAL
  -> HIGH_CANDIDATE
  -> 回落达到15%：HIGH_CANDIDATE_PULLBACK
  -> 回落达到30%：实际高点当天回标 HIGH_CONFIRMED
       当天进入 TROUGH_CANDIDATE
  -> 低点保持5个交易日：TROUGH_REGION
  -> PEAK_1 -> TROUGH_REGION -> PEAK_2 -> ...

任一活跃阶段回落达到35%（优先于波峰、波谷判断）：
  -> CYCLE_ENDED：旧周期永久结束，开始跟踪反转候选低点
  -> 低点保持10个交易日：REVERSAL_CONFIRMED
       后续跌破该低点：回到 CYCLE_ENDED，新低重新计时10天
  -> 后续达到前120日最高收盘价：新 cycle_id，从 HIGH_CANDIDATE 重新开始
```

高点确认后、行情结束前，如果收盘价严格高于原参考高点，当日改为
`INVALID_HIGH_NEW_HIGH`，原周期失效，并以该日新高开始下一个候选周期。

35%结束规则一旦触发，后续涨回结束价位之上也不会恢复旧周期。此后只跟踪反转低点，
不再生成该周期的 `TROUGH_*` 或 `PEAK_n`。新周期仍要求120日新高，反转确认本身不启动新高位周期。

## 每个状态的定义

### 普通与初始高位

| 值 | 枚举 | 中文状态 | 精确定义 | 策略二分类 |
| ---: | --- | --- | --- | --- |
| `0` | `NORMAL` | 普通状态 | 尚未进入高位周期。常见于历史数据不足120个交易日，或收盘价未达到前120个交易日最高收盘价。 | 非做空范围 |
| `10` | `HIGH_CANDIDATE` | 最高点候选区域 | 收盘价达到前120日最高收盘价时启动。候选期内遇到更高或相同收盘价更新参考高点；从参考高点回落不足15%时保持此状态。 | 做空范围 |
| `15` | `HIGH_CANDIDATE_PULLBACK` | 最高点候选回调区域 | 从运行参考高点回落至少15%、不足30%。若涨回跌幅不足15%则回到候选区域。 | 非做空范围 |
| `20` | `HIGH_CONFIRMED` | 已确认最高点 | 后续回落达到30%时，仅将实际参考高点那一天回标为此状态。其余候选和候选回调记录保留。 | 做空范围 |
| `41` | `TROUGH_CANDIDATE` | 反弹波谷候选区域 | 回落达到30%但尚未达到35%，或跌破已有波谷区域下沿，开始寻找低点。更低收盘价更新候选低点，并重新计时。 | 非做空范围 |
| `45` | `TROUGH_REGION` | 已确认反弹波谷区域 | 含低点当天共5个交易日不创新低后，将低点日至确认日回标为波谷区域；区域下沿为低点收盘价，上沿为确认窗口内最高收盘价。 | 非做空范围 |

### 反弹波峰

收盘价严格高于波谷区域上沿，且从区域下沿反弹至少10%的当日，记为该波峰的开始日。
之后只要收盘价仍高于区域上沿，就保持当前波峰；回到区域内时进入 `TROUGH_REGION`；
跌破下沿则进入 `TROUGH_CANDIDATE`，寻找新波谷。任意阶段触及35%结束线时立即停止这套反弹逻辑。

| 值 | 枚举 | 中文状态 | 精确定义 | 策略二分类 |
| ---: | --- | --- | --- | --- |
| `51` | `PEAK_1` | 第一波峰区域 | 第一次从当前波谷反弹至少10%后的波峰阶段。 | 做空范围 |
| `52` | `PEAK_2` | 第二波峰区域 | 第一次回到波谷区域后，第二次满足波峰开启条件；可以复用同一波谷区域。 | 做空范围 |
| `53` | `PEAK_3` | 第三波峰区域 | 第二次回到波谷区域后，第三次满足波峰开启条件。 | 做空范围 |
| `59` | `PEAK_N` | 第N波峰区域 | 第4波及以后的波峰共用此枚举值。实际序号保存在 `peak_number`，中文描述会显示为“第4波峰区域”、“第5波峰区域”等。 | 做空范围 |

### 行情结束与反转点

| 值 | 枚举 | 中文状态 | 精确定义 | 策略二分类 |
| ---: | --- | --- | --- | --- |
| `70` | `CYCLE_ENDED` | 本轮行情结束，等待反转点确认 | `1 - 当天收盘价 / 本轮参考最高收盘价 >= 35%` 时立即进入，固定结束日期，停止旧周期反弹编号。结束当天开始寻找反转低点；后续每次出现更低收盘价都重新计时。 | 非做空范围 |
| `75` | `REVERSAL_CONFIRMED` | 已确认反转点 | 本轮结束后，候选低点当天算第1天，再经过9个该股票有行情的交易日，收盘价均不低于候选低点，第10天输出此状态。相等不重计；低点与确认日分别记录，历史低点行不回标成可观察信号。 | 非做空范围 |

反转确认后，收盘价没有跌破该低点时保持 `REVERSAL_CONFIRMED`；若再跌破，
回到 `CYCLE_ENDED`，从新低重新等待10个交易日，旧周期仍然保持结束。
这个定义不附加上涨幅度要求，横盘也可以满足；后续仍可能跌破已确认低点。

例：本轮高点100元，跌到65元结束。之后低点60元，随后9个交易日收盘价均不低于60元，
第10天确认“60元那天”为反转低点；能够使用这个确认结果的时间是第10天。

`HIGH_DRAWDOWN(30)`、`TROUGH_WAIT_REBOUND(40)` 和 `PEAK_n_PULLBACK(61/62/63/69)`
保留为兼容旧输出的枚举，当前引擎不再产生这些状态，策略二仍将其归入非做空范围。

### 失效告警

| 值 | 枚举 | 中文状态 | 精确定义 | 分类 |
| ---: | --- | --- | --- | --- |
| `90` | `INVALID_HIGH_NEW_HIGH` | 最高点确认后再次创新高，原判断失效 | 进入回落或波峰阶段后，当日收盘价严格高于本周期参考高点。当日输出 `alert_code=CONFIRMED_HIGH_BROKEN`，原周期终止，该新高成为下一周期的候选起点和新参考高点。 | 异常告警，不归入做空范围 |

## 判断边界和字段

- 策略只使用前复权收盘价，不使用盘中高低价、成交量或行业信息。
- 120日新高触发使用 `>=`；15%候选回调、30%高点确认、35%周期结束和10%反弹均包含等于阈值。
- 波峰退出使用波谷区域边界；旧高点失效要求“收盘价 `>` 参考高点”。
- `cycle_id` 是高位周期编号；`peak_number` 是当前周期内的反弹波峰序号。
- `reference_high_*` 保存本周期参考高点；`reference_low_*` 保存当前参考波谷。
- `cycle_end_date/close` 保存本轮首次达到结束阈值的日期和收盘价；`cycle_end_threshold_close` 是参考高点乘以65%（默认参数）。
- `reversal_low_date/close` 保存结束后的候选/已确认反转低点；`reversal_confirm_date` 仅在确认后填写。确认日期不回填至低点日。
- 结束后的 `peak_number` 保留结束前编号用于追溯，但不会再递增；新周期清零。
- `total_mv` 和 `circ_mv` 分别是对应交易日的总市值、流通市值，来自本地
  `daily_basic`。CSV/JSON 保留 Tushare 原始单位万元，报告和图表换算为亿元展示。
- 高位热度相对前10日均价，波谷/波峰热度相对区域下沿；热度不参与状态转换。
- `HIGH_CONFIRMED` 与 `TROUGH_REGION` 包含事后回标，不能将回标日等同于当日已知信号。反转确认没有回标状态，图上的历史低点标记会明确写出确认日期。
- 高点确认30%和结束35%相差5个百分点：连续下跌的股票可能没有任何反弹波峰就结束，这是本次规则的预期行为。

以上“做空范围”只是项目中筛选方案二对状态的程序分组，不代表具体交易点，也不构成投资建议。

## 状态做空回测报告

使用 `--write-report` 时，保存 `states.csv`，另生成以下四类状态回测报告。
当前保存函数不输出状态摘要的 `report.json` / `report.md`，摘要渲染函数仍保留。

- `short_trade_backtest.md`：全部可识别交易；
- `short_trade_backtest_avg_mv_below_300yi.md`：持有期间平均总市值低于300亿元；
- `short_trade_backtest_avg_mv_at_least_300yi.md`：持有期间平均总市值大于等于300亿元。
- `short_trade_backtest_lendable_YYYYMMDD.md`：融券状态正常的固定股票池，包含可用数量为0的股票；日期为实际融券快照日期。

`if args.write_report:` 后，先在全部输入状态上计算一次交易，再派生以下四部分，
每部分只保存一份完整报告：

| 部分 | 范围 |
| --- | --- |
| 整体 | 全部已加载股票的交易 |
| 整体300亿以下 | 每笔交易持有期间平均总市值 `<300亿元` |
| 整体300亿及以上 | 每笔交易持有期间平均总市值 `>=300亿元` |
| 可融券 | 报告日当天或之前最近一份名单，融券状态正常，不限制可用数量 |

统一入口是 `backtest_index.html`。四部分均可用时共生成4份报告，每份有MD/HTML两个格式。
报告包含本池子的全部交易和统计，不按 `positive` / `negative` 拆分；正负收益分类只用于画图。
找不到报告日或更早融券名单时，入口明确说明缺失，可融券部分不生成；显式指定不存在的文件会报错。

每类回测报告都会同时生成 `.md` 和同名 `.html`。Markdown 版保留便于
查看源文本的表格；HTML 版取消中间窄版心，使用整个浏览器窗口展示完整的20列
逐笔交易明细。Markdown 报告顶部也提供对应宽屏 HTML 版的链接。

每笔交易的平均总市值，是从开仓日至平仓日、失效日或报告日之间，所有存在
`daily_basic.total_mv` 的交易日取算术平均。Tushare 的单位为万元，因此300亿元对应
`total_mv=3,000,000`。边界统一放入“大于等于300亿元”组；整个持有区间都没有市值
数据的交易不会强行归类，并会在分组报告开头显示排除数量。报告明细同时展示平均总市值
和实际参与平均值计算的交易日数量。

可融券股票池默认从
`data_cache/securities_lending/daily/YYYYMMDD.xls` 读取，也可通过
`--lending-file` 指定。默认优先使用报告日名单，没有则取此前最近的快照，在报告与文件名中
明确标注实际日期，不会使用未来快照。保留融券状态“正常”和有效代码，取消数量大于0的限制。
该报告使用这份融券快照筛选整段历史交易，适合回答“名单内股票组成的池子中，
策略历史表现如何”，但不能证明历史信号发生时同样有券源。报告没有计入
历史可借数量变化、融券费率和强制归还风险。

这些报告使用以下交易规则：

- 每周期首次进入 `HIGH_CANDIDATE_PULLBACK`，按当日收盘价建立一笔候选回调做空交易；
- 默认不再以 `PEAK_n` 开仓；这些状态继续用于状态观察和画图；
- 候选回调交易在首次进入 `TROUGH_CANDIDATE` 或 `TROUGH_REGION` 时按收盘价结束；
- 尚未结束的任意交易遇到 `CYCLE_ENDED` 时按当天收盘价退出，记录 `status_reason=CYCLE_END_DRAWDOWN`，计入已完成交易统计；已有更早退出的不改变；
- 在前述退出点均未出现时，遇到 `REVERSAL_CONFIRMED` 也按确认日收盘价退出，不使用更早的低点日期或低点价；
- 所有退出点取最早出现者。正常新数据中 `CYCLE_ENDED` 会早于 `REVERSAL_CONFIRMED`，因此通常提前平仓；反转退出用于兼容只有反转确认而没有周期结束记录的输入；
- 同一状态连续出现时不重复开仓，不同股票和不同周期不会交叉配对；
- 出现 `INVALID_HIGH_NEW_HIGH`，或周期已经切换但没有出现对应结束状态时，
  该交易标记为“已失效”；报告日仍未出现结束状态则标记为“持仓中”；
- 已失效和持仓中的交易不计入已完成交易的胜率、平均收益和复利统计，
  但逐笔明细保留截至失效日或报告日的浮动收益、MFE、MAE 和最大回撤。

回测只使用实际输出的候选回调记录开仓，不将事后回标的
`HIGH_CONFIRMED` 当成开仓信号。原有反弹波谷回标仍会影响历史退出时间，
需结合 `trough_confirm_date` 解读；本次只确保新的周期结束和反转确认不回填交易日期。

报告中的主要指标定义如下：

| 指标 | 定义 |
| --- | --- |
| 做空收益率 | `1 - 平仓价 / 开仓价`；大于0为盈利，小于0为亏损。 |
| 胜率 | 已完成交易中，做空收益率严格大于0的交易数 / 已完成交易数；收益为0单列为“平”。 |
| 持有交易日 | 从开仓到结束所跨越的该股票交易日数量，不包含开仓日。 |
| MFE | 持仓期间最低收盘价对应的最大有利收益，即 `1 - 最低收盘价 / 开仓价`。 |
| MAE | 持仓期间最高收盘价相对开仓价的最大不利涨幅，即 `最高收盘价 / 开仓价 - 1`。 |
| 单笔最大回撤 | 以 `2 - 每日收盘价 / 开仓价` 构造单笔做空权益曲线，计算从历史峰值到后续低点的最大跌幅。 |
| 逐笔复利收益 | 按平仓日顺序连接所有已完成交易的收益；仅用于信号比较。 |
| 逐笔复利最大回撤 | 上述逐笔复利曲线的最大回撤。 |

做空亏损可以超过100%（例如开仓价10元、平仓价25元，收益为-150%）。
若已完成交易中存在这种交易，逐笔复利收益及其最大回撤显示为 `-`，表示当前
净值模型不适用；逐笔真实亏损、平均收益和胜率仍正常统计。若没有超过100%的亏损，
但有恰好亏损100%的交易，则复利收益为-100%、最大回撤为100%，资金归零后不再复投。

由于不同股票的交易可能重叠，逐笔复利指标没有考虑资金占用、仓位分配或组合并发，
不等于可直接执行的组合净值。所有统计均未计手续费、滑点、融券成本、涨跌停限制和
实际可融券约束。

报告会将尚未结束和提前失效的信号单列，它们不进入已完成交易胜率。
解读胜率时需要同时查看持仓中数量、失效数量、持有时间和持仓内回撤。

不按最新状态筛选。若填写了代码但全部格式无效，会报告错误，避免误跑全部股票。

图表保存在状态文件同目录的 `charts/` 中，打开 `charts/index.html` 查看。
按现有回测收益分类保存到 `positive/`（正收益）、`negative/`（非正收益）和
`unclassified/`（无可用回测收益，仍生成状态图）。行情缺失或价格不一致的股票
会列在入口页的“未生成项目”中。

`charts/index.html` 同时提供四个池子的图表分类入口。整体沿用上述目录；其余入口位于
`charts/scopes/avg_mv_below_300yi/`、`charts/scopes/avg_mv_at_least_300yi/`、
`charts/scopes/lendable/`，每个入口下都有 `positive/index.html`、`negative/index.html`
和 `unclassified/index.html`。它们链接到已有个股图，便于在不同池子内查看同一股票。

图表分类按每个池子内的股票汇总：已完成交易 `return_pct` 加持仓中/已失效交易
`mark_return_pct`，合计大于0为 `positive`，小于或等于0为 `negative`。
市值池先按交易持有期间平均市值筛选，再按股票汇总，因此同一股票在两个池子里的
收益分类可能不同。没有交易信号的图在整体池和所属融券池的 `unclassified` 中保留；
没有可用交易平均市值时不加入市值池。这是按历史结果分类检查案例，不是组合收益。

画图也支持 `--lending-file` / `--lending-root` 指定融券名单，默认取行情截止日或之前
最近一份名单，融券状态正常即可，不限制可用数量。

新图用灰色菱形标出行情结束日，用灰色虚线显示结束阈值价；蓝色上三角标记事后确认的
反转低点，蓝色空心圆标记实际确认日。鼠标详情分别显示低点与确认日期。
