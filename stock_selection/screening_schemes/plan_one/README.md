# 筛选方案一

方案一依次组合两个独立策略单元：

1. 使用 `industry_index_rebound` 筛选满足条件的申万 L2 行业。
2. 只对这些行业的当前成分股运行 `stock_industry_direction`。
3. 保留同方向比例达到阈值的个股，以“行业 → 个股”形式输出。

排序不使用额外综合分：行业按相对窗口低点涨幅降序，同值时依次按低点后上涨天数、低点后交易日数降序；行业内个股按同方向比例降序。

默认参数：

- 行业窗口：20 个交易日。
- 行业相对低点最小涨幅：5%。
- 行业低点后最少交易日：5 日。
- 行业低点后最少上涨日：4 日。
- 个股方向窗口：20 个交易日。
- 个股最低同方向比例：60%。

运行：

```bash
./.venv/bin/python scripts/run_screening_plan_one.py \
  --date 20260918 \
  --write-report
```

这里只生成研究筛选结果，不提供交易建议。
