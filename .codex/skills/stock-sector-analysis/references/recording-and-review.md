# 历史记录与复盘规则

每次使用 `stock-sector-analysis` 做行情分析时，使用本文件管理历史记录、后续验证和逻辑修正。

## 记录目录

固定目录：

```text
D:\Projects\intelligent-stock-selection-system\analysis_records\sector_analysis
```

按月份归档：

```text
analysis_records\sector_analysis\YYYY-MM\YYYY-MM-DD.md
```

例如：

```text
analysis_records\sector_analysis\2026-06\2026-06-08.md
```

## 分析前必须读取的记录

每次分析前，先检查历史记录目录：

1. 读取最近 5 篇分析记录。
2. 读取本周所有分析记录。
3. 如果用户指定某个板块或个股，搜索历史记录中相关名称。
4. 如果没有历史记录，明确说明“暂无历史记录可检验”。

## 复盘问题

对历史记录至少回答这些问题：

- 之前判断的主线是否延续？
- 之前看强的板块是否继续走强？
- 之前提示的风险是否发生？
- 之前认为弱的板块是否反而变强？
- 之前识别的龙头股是否继续保持核心地位？
- 之前的新闻催化是否被后续行情验证？
- 之前是否遗漏了更强板块或更核心个股？

## 验证结果分类

- 验证：后续走势支持之前判断。
- 部分验证：方向大体正确，但强度、持续性、龙头或节奏判断存在偏差。
- 未验证：后续数据不足，暂时不能判断。
- 被证伪：后续走势明显不支持之前判断，或之前逻辑被新的事实否定。

## 错误修正规则

如果之前判断不准确，不要含糊处理。必须明确写：

```text
之前判断：
后续走势：
错误点：
错误原因：
修正后的逻辑：
后续观察条件：
```

常见错误原因：

- 催化误判：把短期消息当作持续主线。
- 强度误判：高估或低估成交、扩散、持续性。
- 龙头误判：选错核心个股。
- 数据不足：缺少成交、资金、龙虎榜、融资融券、公告或区间表现。
- 来源不足：新闻源、公告源、行业数据源覆盖不够。
- 时间窗口不足：只看当日或近 5 日，没有看近 10/20 日位置。
- 口径冲突：板块分类或资金流口径不一致。

## 信息来源改进建议

如果错误可能来自信息不足，要给用户明确建议：

```text
当前缺口：
建议补充来源：
补充后能改善什么判断：
```

可建议补充：

- 龙虎榜和机构席位。
- 融资融券。
- 北向持股和沪深港通资金。
- ETF 资金流。
- 公司公告和投资者关系记录。
- 行业价格数据和大宗商品数据。
- 板块成分股映射。
- 更完整的新闻源。

## 保存规则

- 除非用户明确说不要保存，否则每次完成分析后保存当天报告。
- 如果当天记录已经存在，不要直接覆盖；先读取旧记录，再追加“更新版本”或询问是否覆盖。
- 保存内容必须包含分析日期、数据接口、新闻来源、历史验证、热门板块、热点个股、修正逻辑和信息来源改进建议。
