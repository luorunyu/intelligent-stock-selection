# 数据入口联合判断规则

当需要把项目级 `tushare-5000-a-stock` skill 的数据入口与新闻信息联合判断时，使用本文件。结构化行情数据只使用 Tushare，不使用 AKShare。

## 目标

用 Tushare 数据验证新闻催化是否真正转化为市场行为。不要只因为有新闻就判断为热点，也不要只因为股价上涨就倒推利好。

## 推荐数据入口

优先使用同项目的 `tushare-5000-a-stock` skill 获取接口说明和代码模板。常用接口如下：

- `trade_cal`：确认分析区间内哪些日期是交易日。
- `index_daily`、`index_dailybasic`：获取指数涨跌、市场成交环境和指数估值/成交指标。
- `stock_basic`：获取 A 股股票池、股票名称、地区、行业、市场和上市日期。
- `daily`：获取未复权个股日线，用于横截面涨跌幅、成交量、成交额。
- `ts.pro_bar`：获取复权行情，适合做个股区间表现和研究口径复盘。
- `daily_basic`：获取换手率、量比、市值、估值等横截面指标。
- `stk_limit`：获取涨停价和跌停价，判断涨停、跌停、连板和短线情绪。
- `sw_daily`：获取申万行业日线，判断行业板块强弱。
- `index_classify`、`index_member_all`：获取行业分类和行业成分股。
- `moneyflow`：获取个股资金流，辅助判断资金参与。
- `moneyflow_hsgt`、`hk_hold`：辅助判断北向资金和持股变化。
- `margin`、`margin_detail`：辅助判断融资融券资金参与。
- `top_list`、`top_inst`：辅助判断龙虎榜和机构席位参与。

## 默认时间窗口

每次分析尽量覆盖以下交易日窗口：

- 最近交易日：判断当前热点。
- 近 3 个交易日：判断短线连续性。
- 近 5 个交易日：判断周度主线。
- 近 10 个交易日：判断阶段性强度。
- 近 20 个交易日：判断位置、趋势和拥挤度。

不要只用当日涨幅判断热点。强热点至少要同时看当日强度、近 3/5 日持续性、近 10/20 日位置和成交确认。

## 字段用途

- 涨跌幅：确认价格强度。
- 成交额：确认资金是否真实参与。
- 成交额环比或区间放大：确认是否放量启动。
- 换手率：确认筹码交换活跃度。
- 量比：确认当日交易活跃度是否异常。
- 涨停/连板：确认短线情绪强度。
- 近 3/5/10/20 日涨幅：确认持续性和位置。
- 行业或板块成分：确认个股是否属于主线核心。
- 资金流：辅助确认资金方向，不单独作为结论。
- 龙虎榜：辅助判断游资、机构或营业部资金参与。
- 融资融券：辅助判断杠杆资金参与。
- 北向持股/资金：辅助判断外资偏好。

## 联合判断矩阵

对每个新闻催化或热点主题，按以下问题判断：

1. 新闻是否新：是否发生在分析区间内或临近区间。
2. 价格是否响应：板块或个股涨幅是否靠前。
3. 成交是否确认：板块或个股成交额是否放大。
4. 扩散是否充分：是否多只成分股上涨或涨停，而不是单一个股。
5. 龙头是否明确：是否出现成交额核心、涨幅核心或连板核心。
6. 公司级逻辑是否成立：公司业务、公告、产品、订单或客户是否与主题直接相关。
7. 持续性是否存在：近 3/5/10/20 日是否延续，而不是单日脉冲。
8. 历史判断是否被验证：之前报告中的主线、个股和风险是否被后续数据确认。
9. 风险是否升高：高位加速、缩量冲高、资金流冲突、公司级催化缺失。

## 结论分层

- 强热点：新闻催化明确，价格、成交、扩散、龙头、持续性和公司级逻辑多数成立。
- 中等热点：新闻催化明确，价格和成交有响应，但扩散、持续性或公司级逻辑一般。
- 弱热点：有新闻但数据响应弱，或只有个别股票异动。
- 资金/情绪驱动：数据很强但新闻或公司级催化不明确。
- 待验证：数据和新闻互相矛盾，或来源不足。
- 被证伪：之前判断为热点或主线，但后续涨幅、成交、扩散或龙头表现明显不支持。
