# 评分规则

当需要对 A 股热门板块和板块内热点个股进行排序时，使用本文件。

## 板块评分信号

基于可获得证据给每个候选板块评分。不要编造缺失数据。

- 价格强度：0-2 分。若板块在最近交易日涨幅靠前，且近 3 日或近 5 日仍保持强势，则分数更高。
- 成交参与度：0-2 分。若板块成交额较高，或成交额明显放大，则分数更高。
- 资金流信号：0-2 分。若多个来源显示净流入或资金参与活跃，则分数更高。平台口径的“主力资金流”噪声较大，只能辅助判断。
- 龙头股强度：0-2 分。若板块有明确龙头股、涨停股或高成交额核心个股，则分数更高。
- 新闻催化：0-2 分。若近期政策、业绩、大宗商品价格、产业事件或公司公告能合理解释板块异动，则分数更高。
- 持续性：0-2 分。若板块不是单日脉冲，而是具备多日强势，则分数更高。
- 数据确认：0-2 分。若新闻催化同时得到涨幅、成交额、换手率、量比、涨停扩散、资金流或龙虎榜等数据确认，则分数更高。

## 个股热度信号

对板块内热点个股进行排序时，优先考虑：

- 行情表现：涨幅、涨停、连板、创新高、成交额或换手放大。
- 板块代表性：公司主营业务和板块主题是否高度相关。
- 公司级催化剂：是否有公告、订单、业绩、产品、客户、产能、并购、政策或行业事件支撑。
- 数据确认：是否有涨跌幅、成交额、换手率、量比、涨停/连板、资金流、融资融券或龙虎榜等数据支持。
- 龙头属性：是否是板块内成交额核心、涨幅核心、辨识度核心或产业链核心。
- 逻辑清晰度：上涨逻辑是否能被事实证据支持，而不是单纯概念联想。
- 风险程度：是否高位加速、是否只有短线情绪、是否业绩兑现不足。

## 置信度标签

- 高：多个独立信号一致，催化因素较新，龙头股表现强，公司级逻辑清楚。
- 中：价格表现和一个辅助信号一致，但催化因素、持续性或公司级逻辑较弱。
- 低：主要依赖单日涨幅，来源一致性弱，新闻较旧，板块内部缺少明确龙头，或公司级催化不明确。

## 风险标记

出现以下情况时需要明确提示：

- 板块或个股处于较高位置，或近期涨速过快。
- 涨幅较大但成交额萎缩。
- 板块行情主要由单一个股带动。
- 只有消息刺激，但缺少成交额确认。
- 不同平台资金流数据互相冲突。
- 使用旧催化因素解释新的价格波动。
- 公司业务和板块主题关联度弱，主要依赖概念映射。
- 找不到公司级明确催化，只能解释为跟随板块或资金情绪。
- 新闻催化和行情数据不匹配，例如新闻很强但板块成交和涨幅无响应。
- 数据很强但找不到新闻或公司级解释，需要标注为资金/情绪驱动或待验证。
